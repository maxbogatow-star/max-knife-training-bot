# MAX Knife Training Bot

Бот MAX для записи на тренировки по спортивному метанию ножа.

## Переменные Railway
- `MAX_TOKEN` — токен бота MAX (секрет).
- `WEBHOOK_SECRET` — придумайте случайную строку 10+ символов: латиница/цифры/`_`/`-`.
- `ADMIN_ID` — MAX user_id администратора. Можно добавить после первого теста.

После деплоя создайте публичный домен Railway и один раз откройте:
`https://ВАШ-ДОМЕН/setup?key=ВАШ_WEBHOOK_SECRET`

Админ-команды:
- `/slot 20.09.2026 18:00 12`
- `/slots`
- `/list 1`
- `/close 1`

Важно: текущая SQLite база на стандартном файловом диске Railway может быть непостоянной при redeploy. Для постоянной эксплуатации подключите Railway Volume или PostgreSQL.
